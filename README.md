# LoveSync — APK বানানোর নিয়ম

1. GitHub-এ নতুন repo বানাও, এই ফোল্ডারের সব ফাইল (লুকানো .github ফোল্ডারসহ) আপলোড/পুশ করো।
2. repo-র Actions ট্যাবে "Build APK" চলবে (নিজে থেকে বা Run workflow চাপলে)।
3. শেষ হলে ওই রানের নিচে Artifacts থেকে LoveSync-apk নামাও, zip খুলে app-debug.apk ইনস্টল করো।
4. দুজনের ফোনেই ইনস্টল করে একই রুম কোড দিলেই সংযোগ।
